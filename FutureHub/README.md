# FutureHub Challenge 🚀

## Sobre o Projeto
Aplicativo mobile colaborativo que conecta pessoas por áreas de interesse e oferece missões gamificadas.

## Instalação

\`\`\`bash
# 1. Instalar dependências
npm install

# 2. Configurar Firebase
# Edite src/config/firebaseConfig.js com suas credenciais

# 3. Iniciar
npm start

# 4. Escanear QR code com Expo Go
\`\`\`

## Features Implementadas
✅ Cadastro e Login com Firebase  
✅ Seleção de Interesses (1-3 áreas)  
✅ 40 Missões Personalizadas  
✅ Mural de Ideias  
✅ Sistema de Curtidas e Avaliações  
✅ Ranking com Badges  
✅ Tema Claro/Escuro  

## Tecnologias
- React Native 0.74.5
- Expo 51
- Firebase (Auth + Firestore)
- React Navigation 6
